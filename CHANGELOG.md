# Changelog

All notable changes to LocalLLM will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2025-03-16

### Added

- Chat interface with streaming token generation
- Conversation history with SwiftData persistence
- Model catalog with 14 open-source GGUF models
- Background model downloads with progress tracking
- Model selector for switching models mid-conversation
- Generation settings: temperature, top-p, max tokens, context size
- Custom system prompts
- Theme support: light, dark, and system mode
- 8 accent color options (purple, blue, green, orange, red, pink, teal, indigo)
- llama.cpp engine bridge with Metal GPU acceleration
- Universal app support for iPhone and iPad
- Conversation management (create, delete, clear)
- Message actions (copy, regenerate, delete)
- Privacy-first design with 100% on-device inference
